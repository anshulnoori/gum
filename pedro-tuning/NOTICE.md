# Source of these procedures

The procedures in `src/main/java/com/anshulnoori/gum/pedro/tuning/procedures/` (`MecanumTuner.java`,
`PinpointTuner.java`, `ForesightTuner.java`, and `Tests.java`) are copied from Pedro Pathing's Quickstart, commit `4f33ef5` ("Bump AutoTune version"),
`TeamCode/src/main/java/org/firstinspires/ftc/teamcode/pedro/procedures/`:
https://github.com/Pedro-Pathing/Quickstart/tree/4f33ef5/TeamCode/src/main/java/org/firstinspires/ftc/teamcode/pedro/procedures

Only the package line is changed. To update them, copy the files from a newer Quickstart commit
and change the package line again.
